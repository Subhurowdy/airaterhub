IMPORTANT BEFORE UPLOAD
1. Replace REPLACE-WITH-YOUR-SUPPORT-EMAIL in contact.html with a real email address you control.
2. Update privacy-policy.html to match the actual live implementation, analytics, cookies, hosting and retention practices.
3. Add an effective date to terms.html and a last-updated date to privacy-policy.html.
4. These are starter templates, not legal advice. Review them for your jurisdiction and actual data practices.
5. These pages link back to index.html. If your dashboard file has a different filename or path, update the links.
6. Upload all HTML files and legal-pages.css to the same directory as the dashboard (or update relative paths).
7. This package does not implement authentication, payment processing, account settings, or server-side contact form submission.
8. Check the pages on mobile and test all links after deployment.

Current known application behavior used for the privacy draft:
- Analysis URL, overall score, report JSON and timestamp are stored in SQLite.
- Account/login/payment functionality is not yet confirmed as implemented.
